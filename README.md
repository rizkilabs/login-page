# Login Page

Halaman login sederhana menggunakan HTML, CSS, dan JavaScript.

## Fitur

- Input email dan password
- Validasi input tidak boleh kosong
- Validasi format email
- Pesan error per input
- Desain responsive (desktop, tablet, HP)

## Teknologi

- HTML5
- CSS3
- JavaScript (Vanilla)

## Cara Menjalankan

1. Clone repo ini
   `git clone https://github.com/rizkilabs/login-page.git`
2. Buka file `index.html` di browser
